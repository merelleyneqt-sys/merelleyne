# Merelleyne — arrangements store

Static one-page site: a playlist of Merelleyne's arrangements for sale. Plain HTML/CSS/JS, no build step.

## Design
- Ultra-minimal, dark, grainy. Refs: link-in-bio card layout (cover → title → list of rows) + gothic band site
  (black/white, condensed high-contrast serif, small mono labels, red accent).
- Fonts: Oranienbaum (serif, titles/buttons), IBM Plex Mono (meta). Accent red `#b3141c`.
- UI text in English.
- Player: fixed bottom bar — left: now playing (title, NN/total, key/BPM; slides in on track change), center: shuffle / prev / play / next / repeat off→all→one + seek line, right: volume (mute + slider, saved; hidden on phones). Slides up after first play. No waveforms.
- Rows: hover = light bg + left marker + slight shift; whole row plays on click. Right side: play + select (+ / red ✓). Selection saved in localStorage. No prices on the site — sales go through Contact.
- Contact: big button under the list (shows selected count) → window with an editable prepared message listing selected tracks; buttons Telegram / Instagram / Email. TG & IG can't reliably prefill, so the message is copied to clipboard first; Email uses mailto with body.
- Perf: no backdrop-filter on list/player (caused stripes + stutter in Safari over the fixed grain); bg/grain on their own layers.
- Cover: round picture-disc vinyl in a static round frame. Photo = `cover.jpg` next to index.html (800×800, user-chosen: red/black skull artwork); without it the disc shows the sigil. Disc spins (40s/turn) only while playing; light sheen stays still. All vinyl look is CSS layers, no image assets.

## Files
- `index.html`, `style.css`, `app.js` — the site. Bump `?v=` in index.html when css/js change (Safari caches hard).
- `settings.js` — contacts (telegram / instagram / email; empty hides the button) and the prepared message text.
- `tracks.json` — the source of truth for tracks (title, key, bpm, file).
- `tracks.js` — GENERATED by `python3 scripts/build_tracks.py` (adds duration). Don't edit by hand.
- `audio/` — previews, re-encoded to 160 kbps MP3 (`ffmpeg -b:a 160k`), lowercase-dashed names.

## Adding a track
1. `ffmpeg -i "<source>.mp3" -ac 2 -b:a 160k -map_metadata -1 audio/<slug>.mp3`
2. Add an entry to `tracks.json`, then run `python3 scripts/build_tracks.py`.
