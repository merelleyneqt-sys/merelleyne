# Merelleyne — arrangements store

Static one-page site: a playlist of Merelleyne's arrangements for sale. Plain HTML/CSS/JS, no build step.

## Design
- Ultra-minimal, dark, grainy. Refs: link-in-bio card layout (cover → title → list of rows) + gothic band site
  (black/white, condensed high-contrast serif, small mono labels, red accent).
- Fonts: Oranienbaum (serif, titles/buttons), IBM Plex Mono (meta). Accent red `#b3141c`.
- UI in English and Russian (switch top-right). Texts live in `i18n.js`; contact message per language in `settings.js`. Admin stays English.
- Player: fixed bottom bar — left: now playing (title, key/BPM; slides in on track change), center: shuffle / prev / play / next / repeat off→all→one + seek line, right: volume (mute + slider, saved; hidden on phones). Slides up after first play. No waveforms.
- No track numbers anywhere, no footer text.
- Name MERELLEYNE is a button → "Links" window (Instagram / Telegram / YouTube / Email…), list in `settings.js` → `socials` (empty url = hidden). Red underline grows on hover.
- Search above the list (fixed 280px width, no resize on focus; filters by title; player prev/next follow the filter). Rows show title + duration only. Row buttons: download (tagged MP3, free) + select; clicking the row itself plays.
- Right-click / long-press menu on a track: play, select, free tagged MP3 download, copy link (`#<file-slug>` deep link).
- Rows: hover = light bg + left marker + slight shift; whole row plays on click. Right side: play + select (+ / red ✓). Selection saved in localStorage. No prices on the site — sales go through Contact.
- Contact: big button under the list (shows selected count) → window with an editable prepared message listing selected tracks; buttons Telegram / Instagram / Email. TG & IG can't reliably prefill, so the message is copied to clipboard first; Email uses mailto with body.
- Perf: no backdrop-filter on list/player (caused stripes + stutter in Safari over the fixed grain); bg/grain on their own layers.
- Cover: round picture-disc vinyl in a static round frame. Photo = `cover.jpg` next to index.html (800×800, user-chosen: red/black skull artwork); without it the disc shows the sigil. Disc spins (40s/turn) only while playing; light sheen stays still. All vinyl look is CSS layers, no image assets.

## Files
- `index.html`, `style.css`, `app.js` — the site. Bump `?v=` in index.html when css/js change (Safari caches hard).
- `i18n.js` — all site texts, `en` and `ru`.
- `settings.js` — contacts (telegram / instagram / email; empty hides the button) and the prepared message text.
- `tracks.json` — the source of truth for tracks (title, key, bpm, file).
- `tracks.js` — GENERATED by `python3 scripts/build_tracks.py` (adds duration). Don't edit by hand.
- `audio/` — previews, re-encoded to 160 kbps MP3 (`ffmpeg -b:a 160k`), lowercase-dashed names.

## Admin (adding tracks) — local only, by design
- User chose: admin runs only on this Mac, no online login. Double-click `Admin.command` → starts `scripts/serve.py` and opens http://localhost:8765/admin/.
- Admin page `admin/index.html`: drop MP3/WAV/AIFF/FLAC → server converts to 160k MP3 in `audio/`, guesses title/key/BPM from the filename (`Name (Gm_135BPM)`, `Name (125BPM)`, `NAME_151`), new track goes on top. Edit title/key/BPM inline (autosave), reorder ↑↓, delete.
- API (in serve.py, bound to 127.0.0.1, rejects foreign Origin): GET/POST `/api/tracks`, POST `/api/upload` (raw body + `X-Filename`), POST `/api/publish`.
- Saving never deletes audio; Publish removes unused mp3s, git-commits audio/tracks.json/tracks.js/cover.jpg, pushes main, then runs `scripts/deploy.sh`.
- `admin/` must NOT be deployed publicly (it's harmless without the API, but keep it out of the deploy).

## Deploy safety
- `scripts/build_dist.sh` copies an explicit file list — when adding a new .js/.css, add it there. It now fails if index.html references a file missing from dist/ (this once shipped the site without i18n.js).

## Hosting
- Live: https://merelleyneqt-sys.github.io/merelleyne/ (GitHub Pages, public repo github.com/merelleyneqt-sys/merelleyne — user approved public).
- Pages serves the `gh-pages` branch = contents of `dist/` only (public files, no admin/scripts/notes). `scripts/deploy.sh` builds `dist/` (`build_dist.sh`, keeps `dist/.git`) and pushes it. Live ~1 min after.
- No GitHub Actions: the gh login token has no `workflow` scope, so deploy happens from this Mac.
- Don't tunnel the local server: it would expose the admin API.
- Manual way still works: put mp3 in `audio/`, edit `tracks.json`, run `python3 scripts/build_tracks.py`.
